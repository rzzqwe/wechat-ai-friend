# 开源目录整理说明

此目录是独立的开源副本，原本地项目及其运行数据保留在原位置。

2026-10-07 发布前清理：已将本副本运行生成的 `data/` 与 `.venv/` 移到开源目录外备份；本副本没有 `profiles/`、聊天记录或账号凭证。已移除内置音频素材、音色库及离线音频生成工具。首次运行会重新创建本地数据和运行环境；公开示例人格仍在 `examples/persona.md`。

## 已包含

- 全部顶层 Python 模块、运行插件、控制脚本和通用诊断工具源码。
- 不依赖私人语料的回归测试与测试夹具。
- 两个运行入口、依赖安装入口、依赖清单和通用示例人格。
- 六张带绘图代码与 SVG 源码的原创小猫表情。
- README、MIT LICENSE、第三方说明、Git 忽略和行尾设置。

## 已排除

- 密钥文件、账号及人格绑定数据、登录结果和真实模型配置。
- 真人参考人格、原始聊天资料、语音参考录音、会话、诊断输出和历史备份。
- 本机专用运行路径、缓存、虚拟环境和 OpenClaw / Node.js 安装目录。
- 第三方角色表情、全部内置音频素材和音色库。

## 为独立使用做的调整

- 默认示例路径改为 `examples/persona.md`，不依赖私人人格文件。
- 各启动入口共用环境检查，优先复用已经验证的安装；缺失时自动补齐运行组件，使用校验后的下载缓存和安装锁避免重复下载。
- 表情由原创绘图代码生成。语音回复和在线试听使用用户自行配置的 Fish Audio Key 和按陪伴保存的音色；用户从官网获取 Key 并选择音色，开源包不提供音频文件或内置音色。
- 语音和图像集成测试改为使用合成音频与临时生成的图片。
- 全局安装 OpenClaw 时，状态探测可以从 PATH 中定位运行环境。
- 文本服务与语音引擎由用户自行配置，缺失时只提示，不自动下载安装模型。
- 私人语料专用的十项回归测试排除，其他测试保留。

运行后的 `data/` 与 `profiles/` 属于使用者本地数据，已经排除 Git 跟踪。不要把原本地项目的数据目录复制到此开源目录中提交。
