# 详细使用说明

面向 Windows 的本地微信 AI 陪伴工作台。每位绑定用户拥有独立的人格、记忆、会话和表情设置，通过 OpenClaw 的微信渠道进行聊天。

## 功能

- 导入 Markdown 或 TXT 人格文件，生成独立陪伴；支持复制人格和切换人格。
- 扫码绑定多个用户，按真实账号路由到专属代理，避免共享聊天历史和记忆。
- 按陪伴管理表情，内置六张原创小猫图片，支持导入 PNG、JPG、GIF、WebP。
- 按陪伴选择文字或文字和语音模式，使用用户自行配置的 Fish Audio 音色。
- 查看本机接收服务状态及当前账号的聊天记录。
- 在首次绑定和工作台启动时自动补齐语音运行组件，后续模式和音色切换即时生效。

## 环境与安装

需要 64 位 Windows。本项目在 Python 3.12 / 3.13.16、Pillow 12.3.0、Node.js 24.16.0、OpenClaw 2026.9.6 上验证。Windows 以外的系统尚未验证，密钥保存依赖 Windows 当前用户的 DPAPI。

1. 将项目放到自己的文件夹中。
2. 双击 `启动微信机器人.bat`。启动前会自动检查并补齐运行环境；也可以先双击 `安装依赖.bat`。
3. 等待环境检查通过后进入工作台。
4. 输入陪伴名称，选择 `examples/persona.md` 或自己的 `.md` / `.txt` 人格文件，点击生成陪伴。
5. 填写模型服务地址、模型名称和 API Key。模型地址需要兼容 OpenAI Chat Completions；图像理解能力由所选模型决定。
6. 选中陪伴，点击绑定用户 / 扫码，用该用户的微信扫描二维码并授权。

工作台启动、独立 OpenClaw 启动、扫码绑定、启动账号和网关重载共用环境检查。优先验证已有安装的实际文件和版本，缺失时补齐 Python 3.13.16（含 Tkinter）、Pillow 12.3.0、Node.js 24.16.0、OpenClaw 2026.9.6 和微信插件 2.4.9；已有兼容版本直接复用。扫码阶段另行配置账号路由与语音组件。兼容修正只对已经核对过的 OpenClaw 2026.9.6 应用；旧配置通过官方 Doctor 迁移。

运行组件和安装包保存在当前用户的 `%USERPROFILE%/.openclaw/wechat-runtime`，项目内保存实际使用路径。这个位置在双击启动和应用内启动时保持一致；旧的应用私有缓存也会迁移复用。安装包校验通过后才使用；第二次启动不重新安装完整组件。路径记录损坏时重新扫描已安装文件，文件缺失时优先复用缓存安装包。多个窗口共用安装锁，后打开的窗口等待并复用结果。下载中断或校验失败可以重试，未完成的文件不会当成安装成功。文本模型、语音服务与音色仍需用户自行配置。

安装和扫码需要联网。安装过程中请保留窗口，失败信息会显示在工作台及扫码窗口中。微信授权入口是否可用，以微信客户端的实际情况为准。用户通过微信中的 ClawBot 对话聊天，电脑上的网关需要持续运行。

三个 bat 入口会在启动窗口显示实时进度：当前步骤、正在检查或安装的组件、已就绪状态，以及失败所在步骤。下载显示实际百分比、已下载大小和速度；安装日志即时输出，长时间无输出时每 5 秒显示等待耗时。总步骤表示流程进展，安装过程不显示估算百分比。工作台在窗口真正打开后显示完成，OpenClaw 在网关状态检查通过后显示完成。

扫码失败后，可选中原陪伴再次点击“绑定用户 / 扫码”继续绑定。如果陪伴已有绑定关系、账号表格却缺少对应记录，工作台会在打开时或点击绑定时恢复原记录，保留原来的用户标识、微信归属和记忆。账号记录保存失败时不会打开二维码，解决保存问题后可以重试。

已有微信插件优先读取 OpenClaw 2026.9.6 的官方安装索引，并核对包、清单校验值、入口文件和依赖；不完整或有歧义时回退完整检查。同一次绑定会复用已经通过的检查。扫码窗口逐阶段显示耗时；首次配置文本模型和后台服务仍需等待，环境检查的耗时不包含微信接口生成二维码的耗时。

已经初始化的 OpenClaw 2026.9.6 环境更新文本模型时，仅用官方配置生成器保存地址、模型名和 Key，保留网关、用户路由、陪伴目录及其他服务商设置；不重新执行初始化向导或后台安装。首次环境尚未初始化、使用配置包含文件或运行版本不属于已验证版本时，会回退官方初始化流程。窗口会分别标明快速保存和完整初始化。

完成安装后，也可以双击 `启动OpenClaw.bat` 单独启动后台网关。

## 语音与表情

文本模型需要使用者自行准备服务并填写地址、模型名和 Key。工具不下载或安装文本、语音模型，也不自动选择默认文本模型。

请先到 [Fish Audio 官网](https://fish.audio/)获取自己的 API Key，并选择音色、取得音色 ID。选择陪伴后，点击“语音配置”，填写这两项。Key 使用 Windows 当前用户加密保存，可在所有陪伴间共用；音色 ID 按陪伴独立保存。保存配置不请求接口、不上传录音，不下载或安装语音模型。使用者需自行确保具有所选音色的使用许可。

还没有生成陪伴时，两项也可以直接填写，保存为默认配置；之后新建的陪伴会独立带入该音色，语音模式仍默认文字。更改默认音色不会改动已有陪伴的配置。

配置完成后选择“文字和语音”。需要语音的回复实时发送给 Fish Audio 合成 WAV，再以音频附件发送。接口固定请求 `s2.1-pro-free`，与本地版一致；额度、可用性和音色权限以服务方为准，失败保留文字，不自动切换模型。未配置 Key 或音色时只提示并保持原模式。

开源包不提供音频文件、内置音色或预填的音色 ID。点击“试听音频”会使用已配置的 Key 和音色 ID，实时合成短句“你好，这是我的声音。”，生成后在试听窗口播放，通常为几秒。再次播放使用已生成的文件，不重复请求接口。未选陪伴时试听默认配置，选中陪伴时试听该陪伴的配置；未配置时只提示。试听会调用 Fish Audio，额度和可用性以服务方为准。

每个陪伴的表情库互相独立。模型按内容选择文字、表情或语音；用户也可以明确要求回复形式。外部编辑陪伴的 `SOUL.md` 后，打开的工作台会定期同步，从下一轮聊天生效。

初始化语音组件或修改账号路由可能重载共用网关，其他账号会短暂重连。已有配置完整时不重复重载。

扫码时优先直接使用已经核验的腾讯插件二维码与凭证保存组件，窗口会区分“正在请求二维码”和“等待手机授权”。后台已运行时，只暂停微信接收并禁用临时扫码账号，保留后台进程；确认授权后先保存账号及专属人格，再恢复接收。无法核验暂停状态时回退为完整暂停。扫码后后台准备慢或启动失败不会撤销已保存的绑定，此时查看运行状态或点击“启动账号”，不必重新扫码。

扫码成功会保存仅属于本次操作的回执，并核对真实账号索引、登录凭证和陪伴归属。即使扫码进程随后异常退出，只要这三项完整，就继续保存专属路由；旧回执或不完整凭证不会被当作成功。

关闭扫码窗口导致操作中断时，下次启动会恢复原有账号的开关；新出现但尚未保存专属路由的凭证保持停用，防止落到默认人格。扫码期间暂时不能修改账号启停。

解除绑定只停止选中账号、删除它的登录凭证并移除本地绑定，不停止或重新启动整个后台。未完成扫码的记录直接在本地解除。人格文件、记忆和聊天记录保留；如果尚未确认账号停止或清理中断，凭证或重试记录会保留，修复后可再次解除。

Windows 后台明确保存数据和配置路径，旧服务只修复一次。已支持的 2026.9.6 使用原有服务管理功能直接启停；管理进程省去重复初始化，编译缓存保存在 OpenClaw 状态目录的 `runtime/node-compile-cache`，首次建立后复用。只有使用自定义模型的陪伴专用环境才缩小默认组件加载范围，明确配置的其他插件、原有加载清单和其他类型的代理保留。账号启停单独保存设置，由后台自动应用，不为每个账号重启全部后台。

## 本地数据

运行后会自动建立本地目录，以下内容均在 `.gitignore` 中排除：

- `data/`：工作台配置、加密密钥、账号绑定、运行状态和诊断结果。
- `profiles/companions/`：使用者导入的人格副本、语音和表情设置。
- `backups/`、`video_extract/`：本地备份和可选的私人来源资料。
- `.venv/`：本地 Python 环境。

OpenClaw 默认将工作区、模型凭证和历史保存在当前用户的 `.openclaw` 目录。模型服务会接收到实际聊天内容。每位用户和人格组合使用独立的工作区与会话；切回原人格时恢复对应记忆。

环境检查会在 `data/runtime.json` 和 `data/python-runtime.json` 保存已经验证的运行路径。也可参考 `examples/runtime.example.json` 指定自行维护的 Node.js 和 OpenClaw 路径；只要实际版本兼容且文件完整，就会优先复用。运行环境示例不包含真实路径和密钥。

如果本机已有本工具此前安装的兼容环境（OpenClaw 状态目录下的 `wechat-runtime`），也会被识别和复用。自动补齐的组件放在用户缓存目录中，不依赖 winget 识别，也不修改系统 Node.js 安装。

本目录没有私人聊天记录、真人参考人格、实际账号信息或本机运行配置。`examples/persona.md` 是全新编写的通用示例。

## 开发与验证

```powershell
.venv\Scripts\python.exe -B -X utf8 -m unittest discover -s tests -q
.venv\Scripts\python.exe -B -X utf8 tests/verify_voice_workbench.py
.venv\Scripts\python.exe -B -X utf8 tests/verify_binding_recovery.py
node tests/verify_native_paths.cjs
```

测试使用临时目录和模拟接口，不需要真实 Key 或微信扫码。读取私人历史语料的旧回归用例没有放进开源版，通用解析、脱敏和隔离测试保留。`tests/verify_*` 中其他 OpenClaw 集成脚本需要本机已安装相应运行环境；内部模块名与所核对的 2026.9.6 对应。

仓库附有 `.github/workflows/tests.yml`，上传后会在 Windows 上运行测试。配置方式参考 [setup-python](https://github.com/actions/setup-python) 和 [setup-node](https://github.com/actions/setup-node) 的官方说明。这个工作流尚未在 GitHub 上运行。

`scripts/` 还保留人格检索、评估、语音分析和诊断工具的源码。这些可选工具需要使用者自行提供获得授权的资料、模型设置和测试输入，不随包提供原始研究数据。
